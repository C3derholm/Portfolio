# Andreas Cederholm – Utvecklarportfölj

En personlig utvecklarportfölj byggd med HTML, CSS och JavaScript.

## Om projektet

Portföljen presenterar mig som utvecklare med sektioner för min resa, 
kunskaper, projekt, referenser och kontakt.

## Tekniker

- HTML5
- CSS3
- JavaScript (Vanilla)
- Git & Github
- Flexbox/Grid

## Metoder och principer

- Flexbox och CSS Grid för layout
- Responsiv design med clamp(), min(), max() och media queries
- Formulärvalidering med JavaScript och inline felmeddelanden
- Fetch API för kontaktformulär (Web3Forms) och väder-API (OpenWeatherMap)
- Canvas API för animerad bakgrund i hero-sektionen

## Användning

Öppna index.html i en webbläsare. Ingen installation krävs.

## Kända problem

 Platsen i väder-API:et är hårdkodad till Skövde och visar inte besökarens faktiska position.
